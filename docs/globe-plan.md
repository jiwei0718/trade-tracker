# 3D 地球儀規劃(2026-10-10)

目標:可拖拉、縮放的 3D 地球,用弧線呈現國家之間的貿易協定,作為協定追蹤工具的展示頁。
先在電腦版(桌面 App)完成,之後同一份程式在 Android App 沿用。

## 現有資料盤點

| 項目 | 現況 | 需要做的 |
|---|---|---|
| 協定 | 775 個(雙邊 519、複邊 203、區域 27、多邊 12…) | 直接使用 |
| 可畫成弧線的協定 | 610 個剛好兩方;55 個三方以上 | 三方以上:兩兩連線或連到集團中心點 |
| 只有單一集團的協定 | 110 個(例如東協自由貿易區、WTO 多邊協定) | 不畫弧線,在集團中心畫光圈 |
| 弧線數量 | 集團用中心點表示:約 1,800 條;集團展開成會員國:約 6,000 條 | 預設用中心點,點選集團時才展開會員 |
| 國家座標 | `countries` 表有 lat/lng 欄位,但 211 國都是空的 | 依 Natural Earth(公有領域)計算標示點填入 |
| 集團與歷史國家座標 | 中美洲、太平洋國家、捷克斯洛伐克等約 15 個代碼沒有位置 | 組織用總部或成員重心;歷史國家用現今對應國家的位置 |

## 技術選擇(建議)

- **globe.gl / react-globe.gl**(MIT 授權,以 three.js 為基礎):內建地球、國家多邊形、弧線、光圈、標籤圖層,
  數千條弧線仍順暢,開發量最少。
- 用 **Expo DOM 元件**(`'use dom'`)包起來:同一份程式在電腦版直接執行,在 Android App 裡以 WebView 執行,
  不用為手機另寫一套。
- 國家邊界:Natural Earth 110m(公有領域),由 `world-atlas` 套件提供。
- 地表樣式二選一(見下方決定 3)。

不建議:Cesium(太重)、deck.gl GlobeView(偏數據圖表、手機支援差)、自己用 three.js 從頭寫(工作量大)。

## 功能設計

**基本**
- 拖拉旋轉、滾輪/雙指縮放;閒置時緩慢自轉。
- 弧線顏色依狀態:已生效(綠)、已簽署(藍)、談判中(橘)、已失效(灰);粗細依同一對國家的協定數。
- 國家依協定數量深淺上色(可切換)。

**互動**
- 點國家:只顯示這個國家的弧線,側欄列出它的協定(連到現有協定頁、國家頁)。
- 點弧線:顯示協定名稱(中文與原文)、狀態、日期,可點進協定頁。
- 點集團(歐盟、東協…):展開到成員國,顯示以集團名義簽署的協定。

**展示亮點**
- 時間軸播放:從 1947 年拖到今天,弧線依簽署或生效年份逐一出現(呼應「歷史時期」頁)。
- 「最新動態」圖層:近 30 天有動態的國家顯示脈動光圈,點了直接看動態。
- 臺灣視角:一鍵聚焦臺灣,顯示我國的協定、申請中的 CPTPP 等。

**篩選**:協定類型、狀態、時期、議題標籤(數位、農業…),沿用「瀏覽」頁的篩選邏輯。

## 分階段

| 階段 | 內容 | 完成時看得到 |
|---|---|---|
| 0 技術驗證 | DOM 元件 + globe.gl,畫出國家與 50 條弧線;量測 1,800 條弧線的流暢度 | 一個可拖拉的地球 |
| 1 資料層 | 補國家與集團座標(寫入 `countries`、`organizations`);由 `agreements_full` 產生弧線與光圈 | 全部協定的弧線,依狀態上色 |
| 2 互動 | 點國家、點弧線、集團展開、側欄、連到現有頁面 | 可以用地球找協定 |
| 3 展示功能 | 時間軸播放、最新動態圖層、臺灣視角、篩選 | 簡報可用的展示頁 |
| 4 打磨 | 樣式、效能、深色模式、無法使用 3D 時的替代清單 | 正式放進側邊欄 |
| 5 Android | 確認 DOM 元件在手機上的表現(和 App 上架一起做) | 手機版地球 |

## 需要決定的事

1. **放在哪裡**:新增側邊欄「地球儀」分頁(建議),或取代現在的「地圖」分頁。
2. **集團怎麼畫**:預設用一個中心點代表集團、點選才展開成員(建議),或一律展開成所有成員國(約 6,000 條弧線,較亂)。
3. **地表樣式**:簡潔的國家多邊形配深色背景(建議,弧線最清楚,也能依協定數上色),或衛星影像地表(NASA Blue Marble,公有領域,較寫實)。
4. **時間軸依據**:簽署日期或生效日期(建議預設生效,並可切換)。
